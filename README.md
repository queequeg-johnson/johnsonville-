The purpose of this project is to pull real-time weather data and perform some statistical analysis on it

What data that is will largely be driven by what statistical analysis is done, and that statistical analysis
will be driven by some goals.

Our goals, however, are at this point *unknown*. For that reason we're just going to compile a list of interesting 
stuff, until we find something that constitues a goal, a method, and a dataset!

So, our first goal is to find:
1) Goal
2) Method
3) Dataset

From there we could build out to have a user interface, realtime data, and cool visual stuff!

But again, for now, we are just building :)
